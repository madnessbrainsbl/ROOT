# 75-second demo script

| Time | Screen | Narration |
|---:|---|---|
| 0–8s | Landing and cover | “RØOT is an offline-first AppSec practice range. It runs locally without a cloud account.” |
| 8–22s | A01 theory | “Choose an OWASP category, understand the trust boundary, and map it to CWE.” |
| 22–38s | Challenge and flag | “Work through a controlled browser simulation. Hints stay available without touching a live target.” |
| 38–50s | Vulnerable/fixed code | “Compare the failure with a focused remediation, then verify the lesson with a quiz.” |
| 50–62s | CVE catalog | “Investigate a small public CISA KEV and CVE List V5 snapshot through local search or SQLite.” |
| 62–70s | Chains and tools | “Move from theory to payload references, attack chains, command builders, and report structure.” |
| 70–75s | Docker command | “Clone it, run `docker compose up --build`, and tell us which lab should improve next.” |

Record at 1920×1080, zoom 110%, and hide personal browser data. Do not show
credentials, third-party targets, or unverified vulnerability claims.
