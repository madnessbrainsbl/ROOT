# Changelog

## [Unreleased]

## [0.1.0] - 2026-07-22

### Added

- Bilingual landing pages and shareable application routes.
- Public CISA KEV and CVE List V5 seed with provenance.
- Read-only SQLite CVE API, Docker healthcheck, and release CI.
- English and Russian documentation plus launch materials.

### Changed

- Split the application data catalog by domain.
- Improved wide-screen, mobile, CVE-table, and attack-chain behavior.

### Removed

- Proprietary CVE synchronization, credential handling, and startup downloads.
- Unused libraries, duplicate fetchers, screenshots, and generated artifacts.
