# Contributing to RØOT

1. Open an issue describing the problem or proposed learning outcome.
2. Keep changes focused and do not add production dependencies without prior
   agreement.
3. Add or update the smallest test that proves the behavior.
4. Run `python -m pytest -q` and `node --test tests/*.test.js`.
5. Use a Conventional Commit message such as `fix(cve): validate pagination`.

Content contributions must identify their sources and licenses. Do not submit
proprietary material, secrets, live target data, copied paid training content,
or payload collections without compatible attribution.

By submitting a contribution, you agree that it may be distributed under the
Apache License 2.0 and that you have the right to provide it.
